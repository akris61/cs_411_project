Transaction — attach high-renewable regions to a dashboard (Stage 4)

Sets isolation READ COMMITTED, runs START TRANSACTION, locks the dashboard row, clears dashboard_regions for that dashboard, inserts regions whose 2010–2019 Renewables average beats the global average (join + group + subquery), updates dashboards.updated_at, then COMMIT (or ROLLBACK on error).

Stored procedure (Stage 4)

CALL sp_stage4_region_category_totals(region_code) — join + group + correlated subquery in HAVING.
